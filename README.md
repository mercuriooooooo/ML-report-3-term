## Описание проекта
Данный репозиторий содержит программную реализацию интерактивного веб-сервиса (дашборда), разработанного в рамках выполнения РГР. Сервис объединяет две комплексные задачи интеллектуального анализа данных:
1. **Задача бинарной классификации (Card Fraud):** Распознавание и фильтрация мошеннических транзакций по банковским картам.
2. **Задача восстановления регрессии (AirQualityUCI):** Прогнозирование концентрации оксида углерода ($CO$) в атмосферном воздухе на основе экологических факторов среды.

Веб-интерфейс спроектирован на базе фреймворка `Streamlit` и развернут в облачной инфраструктуре `Streamlit Cloud`. Сервис поддерживает сквозной конвейер обработки данных (Data Pipeline) — от разведочного анализа до пакетного и единичного инференса с использованием сохраненных весов обученных моделей.

---

## Архитектура проекта и стек технологий

Проект реализован на языке **Python 3.11** с использованием следующих библиотек:
*   **Интерфейс и деплой:** `Streamlit`
*   **Анализ данных и математические вычисления:** `Pandas`, `NumPy`
*   **Классическое машинное обучение и ансамбли:** `Scikit-Learn`
*   **Градиентный бустинг:** `CatBoost`
*   **Глубокое обучение (Deep Learning):** `TensorFlow / Keras`
*   **Визуализация (EDA):** `Matplotlib`, `Seaborn`

```text
